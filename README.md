```text

├── client/              # React user interface for managing items/records
└── server/              # Express REST API connected to MongoDB
```

---

## ⚙️ Prerequisites & Setup

### Requirements
- Basic familiarity with `JavaScript`
- Git installed on your local machine

### Installation Steps
```bash
git clone https://github.com/JasminPeer/crud_application_using_MERN.git
cd crud_application_using_MERN

# Backend
cd server && npm install && npm start

# Frontend (separate terminal)
cd ../client && npm install && npm start
```

---

## 🚀 How to Use
Navigate to `http://localhost:3000` to create, view, edit, and delete records seamlessly.
